# 分镜脚本（正片约 3:10）

> 下表时间码是策划时的目标值；实际时长以配音和成片为准，成片的章节时间见 `成片/章节.txt`。

> 约定：「旁白」由 TTS 配音，同时作为底部字幕；「花字」是画面上额外出现的强调文字。
> 「录制」列说明这个镜头怎么自动产出（详见《制作方案》）：**录屏** = Playwright 驱动应用录制；**HTML** = 单独写一个 HTML 动画页再录下来；**合成** = ffmpeg 里做的放大、框选、转场。
> 演示日期用 Playwright 把页面时钟设为 **2026-11-01**：当天是森亚露露卡生日（示例角色「露露卡」录制时改用全名）。演示添加的角色是**初音未来**（Bangumi 有生日 8 月 31 日）和**博丽灵梦**（官方没公布生日，用来演示「待确认」）。系统时间不用动。

## 视觉规范

- **画框**：应用录屏不铺满全屏，放在薰衣草渐变底上的圆角窗口里（四周留 48px，带柔和阴影），看起来更精致，也方便放花字。
- **推镜**：关键操作做 1.5–2 倍局部放大，用 ffmpeg `zoompan` 或先裁再缩放实现，推入和拉出各 0.4 秒缓动。
- **鼠标**：Playwright 录屏没有系统鼠标，由录制脚本往页面注入一个假光标（白底靛紫描边的小圆点），点击时出现粉色涟漪（#F472B6）。光标沿贝塞尔曲线移动，不瞬移。
- **花字配色**：主色靛紫；生日相关强调一律用生日粉 #F472B6，和应用里一致。字体用微软雅黑粗体。
- **转场**：段落之间用薰衣草色擦除（ffmpeg `xfade=wipeleft`），段内用硬切。
- **字幕**：旁白字幕底部居中，白字 + 半透明深靛底条；花字放在画面空白处，不挡正在点的按钮。
