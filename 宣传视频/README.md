## 一句话定位

**推日：不再错过推的生日。** 搜名字就能加角色，自动拿到头像、生日和生图 Tag；首页、月历一眼看到谁快过生日，提前两周就开始准备贺图。顺带还能和推聊聊天。

## 视频目标

- **主讲生日提醒**（约 60% 时长）：让观众记住「加角色 → 自动拿生日 → 提前看到 → 来得及画贺图」这条链路。
- **其他功能速览**（约 20% 时长）：命令面板、年度选题、AI 助手、AI 推荐选题、标星筛选、头像调整、日夜主题、离线与备份，每个 3–5 秒。
- **简单带一下 AI 聊天**（约 10% 时长）：作为彩蛋式的「还有一件事」，激起好奇，不展开配置细节。
- 结尾只引导三连，不放获取方式（获取方式写在简介里）。

## 目标观众

1. **画师 / AI 绘图爱好者**：每年要给推画贺图，最怕「生日当天才知道」。复制 Tag、建创作任务正好切中。
2. **推活 / 吃谷党**：推很多，生日记不住，想要一个只装自己推的日历。
3. **爱折腾的工具党**：对本地优先、PWA、接自己的 AI 接口感兴趣。

内容以第 1、2 类为主，第 3 类在结尾一句话带过即可，不要讲技术名词吓跑前两类人。

## 规格

| 项目 | 建议 |
| --- | --- |
| 正片时长 | 2:57 |
| 竖屏短版 | 30–40 秒，见《B站发布物料》 |
| 画幅 | 1920×1080，60 fps（录屏的鼠标移动更顺） |
| 分区 | 科技 → 软件应用，或 知识 → 野生技术协会 |
| 风格 | 轻快、温柔，跟应用的「薰衣草雾」配色一致：薰衣草灰白底 + 靛紫 + 生日粉（#F472B6） |
| 配音 | edge-tts 中文女声（晓晓） |
| BGM | Tell Your World 伴奏，从第 0 秒开始；比旁白低约 9 dB，旁白时只轻微压低 |

## 必须如实讲的几点（避免评论区翻车）

- 提醒方式是：**打开应用时首页和日历显示**；想在**不开应用时也收到提醒**，要把日历导出成 ICS 导入手机／电脑日历，由日历软件提醒。应用本身不推送系统通知，视频里不要说「到点弹通知」。
- 生日资料来自 **Bangumi / AniList**，不是所有角色都有公开生日；查不到时会显示「待确认」或「生日未公开」，不会瞎填。
- AI 聊天和生图需要**自己填 AI 接口和密钥**（OpenAI 兼容格式），不配置也能正常用日历。
- 目前是 Windows 上双击启动，需要装 Node.js；数据存在本机浏览器里，不自动云同步，换电脑用 JSON 导出导入。

## 版权注意

- 视频里会出现动画角色头像（来自 Bangumi 的官方图）。这在非商业的工具演示里一般问题不大，但**不要拿官方图做封面主视觉**，封面建议用自己画的图、约稿图或纯 UI 截图。
