# 制作方案（全自动流程）

整支视频由脚本做出来：Playwright 驱动应用录屏，HTML 页面做开场、片头、片尾等动画，edge-tts 配音，Python 合成画面和声音，ffmpeg 编码。脚本都在 [制作/](制作/)。

## 本机工具（2026-10-21 已确认）

| 工具 | 用途 |
| --- | --- |
| Node.js 24 + Playwright 1.64 + Edge | 驱动应用录屏、录 HTML 动画、截封面 |
| ffmpeg 9.0（`C:\tools\ffmpeg`） | 编码、拼接、混音响度标准化、竖屏版 |
| Python 3.12 + Pillow + numpy | 画面合成（窗口、推镜、花字、字幕、转场）、合成 BGM 和音效 |
| edge-tts 7.3 | 中文配音（晓晓） |

## 脚本

| 文件 | 作用 |
| --- | --- |
| `制作/shots.json` | 镜头表：每个镜头的旁白、花字、留白，所有脚本都读它 |
| `制作/config.mjs` | 路径、应用地址（`http://127.0.0.1:4190`）、演示日期 |
| `制作/open-profile.mjs` | 打开录制专用浏览器，让你填 AI 接口和密钥 |
| `制作/check-profile.mjs` | 检查录制浏览器里 AI 配置是否就绪（只输出「有没有密钥」） |
| `制作/tts.py` | 逐句生成配音和字词时间戳 → `素材/tts/` |
| `制作/record.mjs` | 驱动应用录制各镜头 → `素材/rec/<镜头>/` |
| `制作/scenes.mjs` + `制作/scenes/*.html` | 录制 HTML 动画场景，渲染封面 |
| `制作/compose.py` | 逐段合成画面 → `素材/render/seg-<段>.mp4` |
| `制作/build.py` | 配音 + BGM + 音效混音，拼接成片，输出字幕和章节时间 |
| `制作/short.py` | 从成片剪出竖屏短版 |

## 关键做法

### 录制专用浏览器

`素材/profile/` 是独立的 Edge 配置目录，你在里面填过一次 AI 接口和密钥（勾选了「记住密钥」）。每次录制前脚本会清空这个配置里的应用数据（角色、任务、聊天记录等），**只保留 AI 接口配置和已生成的寿星留言**，然后由应用自动载入 17 位示例角色。脚本不读取、不输出密钥。

应用服务用 `.claude/launch.json` 里的 `huiqi-video`（`vite preview`，端口 4190），和你平时用的 4173 工作空间互不影响。

### 慢动作录制

这台机器只有 2 核，按 2400×1350 实时抓屏约 8 帧/秒。所以录制时把页面放慢 7 倍：

- CSS 动画和过渡：CDP `Animation.setPlaybackRate(1/7)`；
- JS 时间（定时器、`requestAnimationFrame`、`Date`）：Playwright 假时钟，每隔一小段实际时间只推进 1/7；
- 脚本里的光标移动、打字、等待也都放慢 7 倍。

无头 Edge 的屏幕广播默认按 CSS 像素出帧（1600×900），启动参数加 `--force-device-scale-factor=1.5` 才能拿到 2400×1350 的清晰帧，推镜放大后文字仍然锐利。

画面用 CDP 屏幕广播逐帧抓取（高质量 JPEG，带时间戳），合成时按时间戳再加速 7 倍，成片约 56 帧/秒。等待网络和 AI 回复的时间会从成片里剪掉（`s.cut`），观众看不到加载过程，而且 AI 的流式回复看起来会快一些。

### 光标

页面里注入一个假光标（白底靛紫描边箭头），沿弧线缓动移动，点击时出现生日粉涟漪。点击和打字的时间点会记下来，混音时在同一时刻放点击声。

### 合成

- 录屏放进薰衣草渐变底上的圆角窗口；HTML 场景直接全屏。
- 推镜区域在录制脚本里随操作一起标注（`s.zoom`），合成时按缓动插值，亚像素缩放，不抖。
- 花字、功能编号卡片、字幕都用 Pillow 画；字幕按配音的字词时间戳切块对齐。
- 段落之间用斜向色带转场（薰衣草 + 生日粉）。

### 声音

- BGM：定稿用 Tell Your World 伴奏（`build.py --bgm 曲子.mp3 --out 文件名.mp4` 可换），从视频第 0 秒开始播放，不按节拍改画面，结尾 2.5 秒淡出；不指定时用 numpy 合成的电钢琴（96 BPM，「王道进行」F–G–Em–Am）。
- BGM 音量按旁白自动定：停顿处比旁白低 9 dB（`--bgm-db` 可调；-18 太小几乎听不见，原来的约 -5 太吵），旁白进行时只轻微压低 22%（约 2 dB，比最初减弱 60%）。
- 旁白出现时 BGM 自动压低。
- 音效全部合成：点击、打字、花字出现的「叮」、段落转场的「嗖」、开场的唱片刮擦和「咚」。
- 成片响度标准化到 -14 LUFS。

## 重新制作

在项目根目录依次运行（预览服务需先启动：`huiqi-video`）：

```bash
python 宣传视频/制作/tts.py
```

```bash
node 宣传视频/制作/record.mjs
```

```bash
node 宣传视频/制作/scenes.mjs
```

```bash
python 宣传视频/制作/compose.py
```

```bash
python 宣传视频/制作/build.py
```

```bash
python 宣传视频/制作/short.py
```

封面：`node 宣传视频/制作/scenes.mjs cover`，一次出四套配色 `成片/封面-<配色>.png`（配色定义在 `scenes/cover.html` 顶部，背景是整页角色库截图 `素材/stills/library-full.png`，字体是 `素材/fonts/` 里的资源圆体）。只想重做某几个镜头时，`record.mjs` 后面写分组名（`home`、`add`、`remind`、`create`、`features`、`chat`、`stills`），`compose.py` 后面写段落号。
